## Work

### GitHunt: web + native Android

A feed of GitHub repositories that learns what you like. My biggest project, and the one I'm actively building.

- Native Android app in Kotlin, Jetpack Compose and Material 3
- Shares a Next.js API and a Neon Postgres database with the website, so your account, clips and feed are identical on both
- Ask AI on any repo, AI search, and background alerts when something starts trending
- CI builds and publishes a release on every push to `main`, and the app updates itself through Obtainium

[Website](https://githunt-aadin.vercel.app) · [Android repo](https://github.com/heyitsaadin/githunt-android) · [Latest release](https://github.com/heyitsaadin/githunt-android/releases/latest)
